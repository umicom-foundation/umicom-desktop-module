Filtering the application catalogue

The category selector on Desk’s Home page works together with its name search. Begin with All applications, type part of an application name, and then select a category.

CategoryWhat it shows
All applicationsEvery application that also matches the name search.
AvailableApplications whose current launch-choice snapshot reports them eligible.
RunningApplications whose snapshot reports them running.
SelectedApplications currently selected in the catalogue, whether or not running.
Needs attentionApplications with an Attention or Failed runtime state.

Filtering changes visibility only. It does not start or stop a process and does not change the selected applications. A running application can be hidden by a filter and still be running. Choose All applications and clear the name search to show the complete catalogue again.

For developers

The screen uses the existing Framework owner. This call belongs inside a host that has created the required objects and keeps them alive:

UmiStatus status = UmiDeskApplicationFilterMatches(&choice, UMI_DESK_APPLICATION_FILTER_RUNNING, &visible);
if (status != UMI_STATUS_OK) {
    /* Keep the existing state and explain the returned result. */
}
