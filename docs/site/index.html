User guide: launch and inspect an application

Desk provides a starting point for the installed products. The application catalogue, executable discovery and process state answer different questions: a product can be registered without being installed, and a started process can still fail before becoming ready.

  1. Start Desk from the installation you intend to use.
  2. Refresh application discovery when executable files have been installed or removed.
  3. Select one installed application and request a launch.
  4. Check the result. If a launch fails, read the reported reason before retrying.
  5. Close the launched application normally, then launch it again to check the lifecycle.

Use disposable workspaces for startup testing. Session transfer, durable recovery and multi-monitor behaviour require their own checks; they are not established merely by a successful process launch. Keep the existing installation when trying a new package.

Support and contribution

When reporting a problem, include the application revision, operating system, exact action and error output. Remove credentials, private account information and personal file content. Use the repository issue tracker for a reproducible defect and the contributor guide for documentation improvements.
